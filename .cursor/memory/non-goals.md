- Claiming new physics or proving AdS/CFT — we run **baby tests** on a toy TFIM simulator.
- 3×3×3 cube (27 qubits) in the browser reference engine — Hilbert space too large for now.
- True 4D WebGL (time as a graphics axis) — emergent time stays scrubber + heatmap.
- Decoherence / Everett branching in the live engine (essay has static toy viz only).
- Picking a clock subsystem from Wheeler–DeWitt — we use explicit Δt or site-based physical clocks.
- Memorizing every user prompt into `.cursor/memory/` — only durable decisions and rationale.
- Replacing `docs/` with memory — research notes stay in `docs/`; memory holds goals and impetus.
